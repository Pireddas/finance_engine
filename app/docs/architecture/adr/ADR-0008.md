# ADR-003 — Restrição de Acesso via Token API Key

**Arquivo:** framework_calculo_de_metricas/architecture/adr/ADR-003.md
**Identificação:** ADR-003
**Origem:** BR-4.1.1.8, EP-5, FS-3.3, US-08
**Status:** Accepted
**Versão:** 1.0

---

## 1. Contexto

A integração com o serviço de cálculo cria um novo ponto de acesso que precisa ser protegido contra uso indevido ou bypass da governança.

---

## 2. Decisão

Restringir o acesso ao motor de cálculo exclusivamente por meio de Token API Key válido e gerenciado.

---

## 3. Justificativa

1. **Segurança Reforçada**
   Apenas o backend autorizado dispara cálculos.
2. **Causalidade de Segurança**
   O token é validado pelo Identity Manager antes do despacho.

---

## 4. Consequências

* Bloqueio imediato com erro **401 Unauthorized** em caso de token inválido ou ausente.
* Validadores de segurança dedicados na camada de infraestrutura.
