# ADR-007 — Classificação Visual e Apoio à Decisão (Cores)

**Arquivo:** `framework_calculo_de_metricas/architecture/adr/ADR-007.md`
**Identificação:** ADR-007
**Status:** Accepted
**Versão:** 1.0

**Origem:** BR-4.3.3, EP-6, FS-3.3, US-12

---

## 1. Contexto

Gestores precisam identificar rapidamente ativos aderentes ou violadores das diretrizes institucionais.

## 2. Decisão

Implementar indicadores visuais **Verde / Amarelo / Vermelho**, baseados em thresholds formalmente homologados pela governança.

## 3. Justificativa

1. **Agilidade:** Leitura imediata do risco.
2. **Padronização:** Cor significa a mesma coisa para todo mundo.

## 4. Consequências

* Exibição obrigatória no relatório de saída.
* Visual auxilia, mas a regra manda.
