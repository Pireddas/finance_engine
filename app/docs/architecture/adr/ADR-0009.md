# ADR-004 — Garantia de Integridade via Execution Hash

**Arquivo:** framework_calculo_de_metricas/architecture/adr/ADR-004.md
**Identificação:** ADR-004
**Origem:** BR-4.1.1.7, BR-5.4, FS-3.4, US-09
**Status:** Accepted
**Versão:** 1.0

---

## 1. Contexto

A imutabilidade dos resultados é princípio central. É necessário garantir que o output entregue seja exatamente o que foi processado.

---

## 2. Decisão

Gerar um **Execution Hash** que vincule de forma imutável o resultado numérico final à sua Execution Identity.

---

## 3. Justificativa

1. **Não Repúdio**
   Impede alteração de resultados consolidados.
2. **Auditabilidade**
   Permite validação completa entre metadados e output.

---

## 4. Consequências

* O backend deve validar o hash de retorno; falhas invalidam a execução.
* Hash e resultado devem ser registrados obrigatoriamente no log append-only.
